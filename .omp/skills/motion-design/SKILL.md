# Motion design — local reference

This skill is an art-direction manual only. `presentation-motion`, user decisions, actual motion references, and the deck DNA have higher priority.

- Name a single motion personality before choosing timing or easing. For an editorial deck, controlled, calm, and precise is more appropriate than playful or energetic by default.
- Let entrance easing decelerate, exit easing accelerate, and use smooth in/out easing only for a visible on-screen state change.
- Match duration to reading weight and distance. Use the smallest number of animated properties: one is direct; two can add polish; more require a clear reason.
- Lead with the primary read. Then reveal only the supporting evidence that benefits from sequence. Keep overlapping motion sparse enough that viewers can follow one idea at a time.
- Motion should explain attention, direction, causality, comparison, or handoff. It does not need ambient loops, particles, secondary shadow motion, or a “three layers” quota.
- Respect stillness, the static settled state, and reduced motion.
