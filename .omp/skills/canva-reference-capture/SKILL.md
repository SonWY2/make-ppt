# Canva 레퍼런스 이미지 저장

Canva 템플릿의 공개 미리보기 슬라이드를 프로젝트 로컬 `references/` 아래에 저장한다. 썸네일 주소를 추측하거나 변형하지 않는다. 각 슬라이드를 실제 브라우저에서 직접 선택해 Canva가 표시하는 큰 미리보기만 저장한다.

## 입력

- Canva 템플릿 URL
- 저장 폴더. 기본값은 `references/canva-<식별자>/`

## 절차

1. 실제 Chromium으로 Canva 템플릿 URL을 연다.
2. 쿠키 동의 화면이 상호작용을 막으면 필요한 선택으로 닫는다.
3. 템플릿의 전체 슬라이드 수를 확인한다.
4. 각 슬라이드를 하나씩 직접 선택한다.
5. 선택된 슬라이드에서 Canva가 제공한 큰 미리보기 URL을 읽는다.
   - `1600w` 자산이어야 한다.
   - 템플릿 경로, 페이지 번호, 서명된 URL을 임의로 바꾸거나 조합하지 않는다.
   - `400w` 썸네일과 `800w` 중간 이미지는 저장하지 않는다.
6. 현재 선택된 큰 미리보기를 프로젝트 저장 폴더에 `canva-01.jpg`처럼 1부터 0 채움 번호로 저장한다.
7. 모든 파일이 JPEG이고 1600×900인지 확인한다.

## 실패 처리

- 큰 미리보기가 나오지 않으면 해당 슬라이드를 다시 선택하고 로딩을 기다린다.
- 큰 미리보기 없이 썸네일만 보이면 저장하지 않는다.
- 로그인, 유료 권한, 다운로드 제한으로 큰 공개 미리보기를 얻지 못하면 성공한 슬라이드만 저장했다고 정확히 보고한다. 원본 디자인 파일이나 권한 없는 다운로드를 우회하지 않는다.

## 경계

- 결과물은 프로젝트 내부 `references/`에만 저장한다.
- 이 이미지는 디자인 분석용 레퍼런스다. 프로덕션 슬라이드는 이 자산을 자동으로 로드하지 않는다.
- 완료 보고에는 파일 수, 파일 경로, 각 이미지의 크기를 포함한다.
