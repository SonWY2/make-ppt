# Reference analysis

## Establish the evidence scope

Name the mode before inspecting visuals. An explicit user mode wins. Without one, requested reproduction of a supplied slide is **RECONSTRUCT** and a new topic or slide is **EXTEND**; a supplied reference alone does not choose the mode.

### RECONSTRUCT — reference evidence

Treat the supplied reference as the composition authority. List its measurable anchors: outer margins, major rectangles, text baselines, image crop boundaries, color fields, grouping, and visual count. Recreate those relationships on the 1600 × 900 canvas before details. Use the reference overlay only while editing to compare silhouette, anchors, hierarchy, and image crop; turn it on and off rather than treating transparency as a substitute for independent inspection.

### EXTEND — deck-led evidence

Treat multiple existing deck slides and the recorded Design DNA as the composition authority. Extract the invariants: recurring anchor and margin logic, typographic and color roles, image framing, spacing rhythm, surface/line/connector semantics, deck furniture, semantic layer ownership, and local production safety. A supplied reference may supplement those visual-language roles, but not the new slide’s composition. Record the new slide’s message, reading path, and topology before composing.

Do not take a supplied reference’s scene graph, placement, coordinates, grouping, or visual count as EXTEND layout evidence, and never directly copy its layout. The new slide may vary its reading path, layout, visual count, diagram topology, density, and silhouette to serve its message while preserving the deck’s DNA. Multiple diagrams require distinct reader questions and a clear relationship. Reference overlays and measurements may support visual-language inspection, but never authority for an EXTEND scene graph, coordinates, grouping, visual count, or composition.

## Implement from the selected evidence

Translate only the selected mode’s evidence to the 1600 × 900 canvas. Keep geometry in the semantic layer that owns it.
