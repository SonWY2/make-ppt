# Reference analysis

## Inspect before composing

1. Name the working mode: **RECONSTRUCT** for a supplied reference, **EXTEND** for a new slide in an established deck.
2. In RECONSTRUCT, list the reference’s measurable anchors: outer margins, major rectangles, text baselines, image crop boundaries, and color fields. Recreate relationships before details.
3. In EXTEND, sample multiple existing slides. Extract the deck’s Design DNA: recurring anchors, typographic scale, image framing, color-role boundaries, density, and slide-to-slide rhythm.
4. Translate the chosen system to the 1600 × 900 canvas. Keep geometry in the semantic layer that owns it.

## Reference overlay

Use the reference overlay only while editing. Turn it on and off to compare silhouette, anchors, hierarchy, and image crop; do not treat transparency as a substitute for independent inspection.
