# DESIGN DNA — FDE introduction / Canva reference / EXTEND

- **Mode:** EXTEND. The FDE content extends the existing production entry point, while the supplied `references/canva-eag78fbchia-slide-01.jpg` through `12.jpg` govern the visual system.
- **Reference family:** clean Korean proposal deck. Slides 01 and 12 establish the white field, deep navy emphasis, thin top rule, compact top metadata, and calm closing space. Slides 04–06 establish the image-led article layout. Slides 03, 07, and 09 use circles only when the message is an explicit set or sequence.
- **Canvas and anchors:** fixed 1600 × 900. Header starts at x=72 / y=52 and its rule runs near y=92. Content uses about 90–118 px outer margins. The user-committed `title-main` frame remains x=118 / y=217 at 650 × 179. The committed `hero-image` frame remains x=853 / y=139 at 637 × 514 and ends at x=1490.
- **Composition:** the Canva references define the visual language—white field, deep navy emphasis, compact metadata, generous whitespace, concise Korean typography, muted photography, and restrained density—not fixed slide blueprints. Choose each slide’s information structure from its FDE message first; reuse a reference format only when it clarifies that message. Avoid literal layout mirroring and never let a visual motif replace explanation.
- **Typography:** Korean sans-serif throughout. Utility text is 12–14 px; content heading 42–60 px, bold, deep navy; body 17–19 px, dark gray, generous leading. No expressive display serif.
- **Color roles:** near-white canvas `#f8f8f7`; deep navy `#273961` for headings, strong fields, and selected emphasis; charcoal `#333333` for copy; neutral gray `#e7e5e2` for quiet fields; hairline `#d7d5d1`. Warm tones are absent unless carried by a real image.
- **Whitespace:** sparse and deliberate. Each reference format preserves a broad white field around its focal message; no layout fills empty areas merely for density.
- **Shape and depth:** use reference-proven forms only when the content earns them: 01 uses photos to establish the role; 02 uses three text panels to name the operational differences; 03 uses circles for three peer concepts; 04 uses process capsules for ordered work; 05 uses bands for distinct collaboration modes. No form exists merely as decoration.
- **Image treatment:** only 01 uses local monochrome architectural photography because the image provides the opening tone. The remaining slides privilege readable FDE explanations over illustrative texture. Reference assets remain edit-only.
- **Content archetypes:** 01 role introduction; 02 rationale for the role; 03 role boundary; 04 field-work sequence; 05 day-to-day collaboration. The selected format makes each message distinct while typography, color roles, header rule, and spacing keep the deck coherent.
